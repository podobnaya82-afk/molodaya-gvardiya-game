# Операция: «Молодая гвардия»

Браузерная игра для школьников 14–17 лет. Каждый участник проходит игру самостоятельно. Без кода сеанса работает автономный режим с локальным рейтингом; режим мероприятия сохраняет результаты в Supabase.

## Презентация перед игрой

Откройте `presentation.html` в браузере и нажмите «⛶ Экран». Листайте слайды стрелками или кнопками снизу. Слайды 5 и 6 содержат подсказки к миссиям 1 и 4. На последнем слайде можно загрузить изображение QR-кода сеанса своей аудитории (PNG, JPG, SVG или WebP) и ввести код сеанса из панели `/admin.html`; затем нажмите «Скрыть настройки». Для общей статистики участники должны открывать **ссылку своего сеанса**, а не общий адрес игры. Презентация работает без интернета; для сохранения в PDF используйте печать браузера в альбомной ориентации.

## Мероприятия и аудитории (Vercel + Supabase)

1. Создайте проект Supabase и выполните содержимое `supabase.sql` в **SQL Editor**.
2. Добавьте на Vercel для проекта переменные `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `ADMIN_PASSWORD`, `ADMIN_SESSION_SECRET` (см. `.env.example`). `ADMIN_SESSION_SECRET` — случайная строка длиной не меньше 32 символов. Храните ключ `service_role` только в переменных сервера Vercel; не добавляйте его в `app.js` или публичные файлы.
3. Повторно разверните проект: переменные окружения применяются к новым деплоям.
4. Зайдите на `/admin.html`, введите пароль, создайте мероприятие и отдельный сеанс для каждой аудитории. Раздайте участникам ссылку сеанса (при необходимости создайте из неё QR-код). Все ссылки мероприятия действуют **8 часов с момента создания мероприятия**, независимо от времени создания отдельных сеансов. Затем вход и отправка новых результатов закрываются, а организатор и игроки видят статус «Мероприятие завершено». Для следующего дня создайте новое мероприятие.
5. Статистика показывает начавших/завершивших игру, средний балл и время, результаты каждой миссии и участников; фильтр доступен по мероприятию и аудитории. Выгрузка CSV учитывает выбранный фильтр.

Псевдоним и игровой результат сохраняются в базе, когда участник играет по ссылке сеанса. При временном отсутствии сети отправку итога можно повторить кнопкой на финальном экране до закрытия вкладки. Прямой вход на обычный адрес игры оставляет результаты только в браузере. Для корректной статистики используйте ссылки сеансов.

## Быстрый запуск

Откройте `index.html` двойным щелчком. Для показа на одном компьютере этого достаточно.

Для проверки с телефона в одной сети можно запустить в папке проекта простой локальный сервер, если на компьютере установлен Node.js:

```powershell
npx serve .
```

Команда покажет сетевой адрес. Откройте его на телефоне или превратите в QR-код с помощью любого генератора QR-кодов.

## Публикация

Исходники: https://github.com/podobnaya82-afk/molodaya-gvardiya-game. Проект опубликован на Vercel: https://molodaya-gvardiya-game.vercel.app. Панель организатора — `/admin.html`. Автоматическая публикация коммитов потребует предоставить интеграции Vercel доступ к приватному репозиторию и подключить Git в настройках проекта. Для участников мероприятия используйте ссылки сеансов из панели: общий адрес игры работает в автономном режиме.

## Состав игры

1. Хронология событий.
2. Учебный шифр.
3. Логическая задача с маршрутом.
4. Сопоставление имён и биографических фактов.
5. Работа с историческими и художественными источниками.
6. Задание на внимание.
7. Финальный код `КРАСНОДОН`.

В автономном режиме псевдоним и локальный рейтинг хранятся только в браузере. В режиме мероприятия псевдоним, время и результаты миссий отправляются на сервер для статистики организатора.

## Личный зачёт

- Участник вводит своё имя перед началом.
- Общее время считается от начала первой миссии до правильного финального кода.
- Главный критерий сравнения — время; при одинаковом времени выше участник с большим числом очков.
- Кнопка «Таблица результатов» показывает результаты, сохранённые на этом устройстве.
- Кнопка «Скопировать результат» создаёт строку вида: `Имя — 08:42, 710 очков`.

В автономном режиме результаты с разных телефонов не объединяются. Для общей статистики создайте мероприятие и ссылки сеансов в панели организатора.

## Что проверить перед мероприятием

- Провести научную редактуру дат и биографических формулировок.
- Проверить игру на телефонах Android и iPhone, которые будут использоваться в школе.
- Убедиться, что школьный интернет открывает адрес игры.
- Напечатать резервные карточки заданий на случай отсутствия связи.
- Вывести QR-код крупно: не менее 12 × 12 см для класса.

## Изменение содержания

Все тексты заданий находятся в `app.js`:

- `timelineEvents` — хронология;
- `missionData` — названия, подсказки и пояснения;
- `people` — биографические факты;
- `sourceStatements` — задание об источниках.

После изменения финальных фрагментов проверьте функцию `renderFinalCode`: сейчас правильный ответ — `КРАСНОДОН`.
